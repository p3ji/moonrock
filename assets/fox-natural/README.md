# Approved naturally curled three-tail fox

The compact sleeping illustration in `natural-three-tails-source.png` was approved by the user. `eyes-half-source.png` and `eyes-open-source.png` are aligned eye-opening edits made with the built-in image-generation tool. Exact prompts are recorded in `generation-notes.json`.

The website renders the sleeping WebP as the unchanged base and masks both eye overlays to the small face region. Only the eyes transition; the moon, body and three curled tails do not move. The fox stays asleep through arrival, then transitions through half-open to fully open as guests scroll down the landing page. Scroll back to close them again.

Original PNG sources are preserved. Runtime exports are optimized transparent WebP files; the server package includes only those three files. The original single-tail and previous three-tail iterations remain available separately for reference.
